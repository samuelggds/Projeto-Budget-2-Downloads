# Sistema de Orçamentos — Downloads

Canal público de instaladores e atualizações do Sistema de Orçamentos, desenvolvido por Samuel Gomes.

**Migração em preparação.** O canal atual continua atendendo às instalações existentes. A versão de transição será publicada nos dois canais antes de qualquer mudança na visibilidade do código.

Este repositório contém apenas documentação e arquivos de distribuição. O código-fonte do aplicativo é mantido separadamente.

## Sobre o projeto

Aplicação web e desktop para gestão de clientes, serviços, estoque e orçamentos, com emissão de documentos em PDF.

[Conheça o projeto e as tecnologias utilizadas](https://github.com/samuelggds/samuelggds/blob/main/portfolio/orcamentos.md)
